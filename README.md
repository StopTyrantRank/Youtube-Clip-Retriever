## Troubleshooting

- **Setup opens and closes right away.** Start it from a Command Prompt in the same folder. The console keeps the message that was closing with the window.
- **Partial extraction leaves the folder incomplete.** Delete the half-extracted folder, extract the zip again into a fresh folder, and start `setup` from there.
- **Corporate laptop blocks the folder.** IT needs to allow the folder. The file is a plain unsigned Windows build inside a plain zip.
- **A second zip raised the warning again.** Windows treats the new file as a new download.
- **Nesting hid the files from the top.** Drop one level. `setup` and the other files are together in the folder below.
- **SmartScreen may prevent the first launch.** This warning occurs because the file is not signed. You can choose to select 'More info' and then 'Run anyway' to proceed.
